## Description
L'outil vianic/kali-cyberpunk-setup est un kit de configuration pour Kali Linux qui permet de personnaliser l'environnement de travail pour les tests de sécurité offensifs. Il installe un ensemble d'outils de pentest sous /opt/tools pour faciliter les opérations de sécurité.

A post-install kit that turns a fresh Kali install into a themed, ready-to-work offensive-security workstation. One script themes the desktop and shells in a cyberpunk dark-teal palette; the other is an fzf-driven installer
